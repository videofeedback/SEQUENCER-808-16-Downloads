The complete drum machine / workflow guide

One drum machine.
Two ways to shape it.

Play finished sounds immediately, or build the sound in front of you. Both workflows give you 16 drums, patterns A–I, a song arrangement, and a complete mix in one Rack patch.

Out-of-the-box samples ↓Synthesized / live sound design ↓

About “synthesized”: here it means shaping recorded drums with live modular processing. Both versions begin with recordings of a real TR-808. The live version uses filters and envelopes; it does not generate the drums from oscillators or recreate the original analog circuits.

Why two sequencers?

One module has eleven sounding lanes plus accent. Five alternate voices share lanes with the toms, rim and clap. These complete patches use an upper source for the main eleven drums and a lower source for five extra percussion sounds, so all sixteen can play together. The sixteen colored buttons are steps, not sixteen independent sample pads.

02

Out of the box: program, mix, play.

Open example 01 for a basic groove or 02 for a song. The prepared kit is ready; no external effects setup is needed.

1 / Start the groove

Select your device in Audio 2 if needed. Press RUN on Clocked. Every example opens stopped.

2 / Edit a drum

Choose the matching pattern letter and a drum lane on its source, then toggle the colored step keys. Adjust that lane’s LEVEL, TONE, TUNING and DECAY.

3 / Perform the mix

Use the mixer’s M and S buttons to drop drums out or isolate them. Save the whole Rack patch when the groove is ready.

Close-up / the sequencer

1 Pattern letters A–I2 Library selector + BROWSE3 Per-lane sound controls4 Sixteen step keys

What you can change

  • LEVEL: volume of the selected drum lane.
  • TONE: negative values darken; positive values filter out lows.
  • TUNING: −12 to +12 semitones. Pitch changes also change playback duration.
  • DECAY: shortens the recorded tail. At 100%, the recording plays its full tail.

What is already in the WAV

The earlier VCF and Percall treatment is rendered into each sample. Turning the sequencer controls back to neutral does not remove that baked-in sound design.

To change that original processing, open the live version. To replace the kit with the untouched recordings, choose Flat Sample in the library selector for the pattern you are editing.

03

Live sound design: follow the signal.

Open example 03 for a groove or 04 for a song. Every drum has a named effects path, and every part of the shaping remains editable.

Sequencer VOICES→Split→VCF→Percall→FADE→Voice level→MixMaster

The Split output also feeds FADE’s dry input. Separate drum triggers from the sequencer fire the matching Percall envelope. The panel’s left-to-right layout is VCF → FADE → level per drum, with one shared four-channel Percall to the right of the group.

Close-up / the four named effects groups

Choose a group to inspect its real controls. Within each group, Percall channels 1–4 follow the four drum labels from left to right.

What each stage does

  1. VCF / timbre: CUTOFF sets the filter frequency, RES emphasizes its edge, and DRIVE changes input drive. The patch uses either the LP or HP output for each recipe.
  2. Percall / envelope: the matching channel’s decay slider sets how long the envelope lasts; its level knob controls output amplitude. A short envelope tightens the drum.
  3. FADE / comparison: 0% selects the dry source, 100% the live processed path. Intermediate settings blend them.
  4. LEVEL / balance: the small level module after each FADE sets that voice’s feed to the main mixer.

Try it / reshape the bass drum

  1. Start Clocked and solo BD on MixMaster. Leave its mute off.
  2. Find 01 Bass Drum in the first effects group.
  3. Turn its FADE to 0% to hear the dry recording, then return to 100%.
  4. Lower the VCF cutoff for a softer attack. Shorten Percall channel 1 decay for a tighter tail.
  5. Clear solo, balance the level against the other drums, and save the .vcv patch.
A fair dry comparison

The sources start with TONE 0, TUNING 0 semitones and DECAY 100%. FADE at 0% bypasses the external effects, but source-level changes and the downstream mixer still apply. Dry and processed paths are not loudness matched.

Find any drum’s recipe

These values come from the saved recipes used to build the patches. The decay time is the envelope’s nominal duration, not the sample’s audible length.

04

The same performance controls.

Mute & solo

M mutes that drum. S isolates it. Multiple solos let you hear a selected combination, including drums from different groups.

A muted drum stays muted even if you solo it. For a missing sound, check its mute, other active solos, group level, and master level.

One transport for both sources

Clocked RUN starts/stops both sequencers. RESET returns them to the beginning. Use BPM and SWING 1 on Clocked for these example patches.

The source displays EXT CLK. Its internal TEMPO and SWING values still save per pattern, but do not control timing while an external clock is connected.

Leave the 8vert clock/reset distribution rows at 100%. Stopping can leave sample tails ringing; reset clears playback.

Browse, preview, assign

  1. On the source you want to edit, select a pattern letter and click BROWSE.
  2. Choose a library or All libraries, then search and select a sound. PREVIEW auditions it; STOP silences the preview.
  3. Choose the destination sample slot and click ASSIGN TO PATTERN …. Assignments belong to that pattern.
  4. Close the browser and save the whole patch to retain both sources and their kits.
Preview routing in these examples

Browser previews leave the module’s MIX L/R outputs. The complete drum machines are wired from VOICES, so preview is not on their normal drum mix. To audition, temporarily connect that source’s MIX L/R to an available monitored mixer channel, keep its level low, and avoid doubling the running drum mix.

Preview does not enter VOICES and ignores per-drum sound controls.

Importing your own samples

Use Sample Library → Import library folder…. Name files [PAD_NUMBER]-[LIBRARY_NAME]-[CUSTOM_SAMPLE_NAME].[format], for example 01-My-Kit-Deep_Kick.wav. The number identifies a sample slot, not a step.

Supported formats are lossless WAV, AIFF and FLAC. Use 24-bit WAV/AIFF or 24-bit FLAC for high-quality recordings; 32-bit float WAV is suitable for processed exports. Mono and stereo files are supported. Keep the source sample rate; upsampling does not add recording detail.

Use the same library name in every file. Library names may contain hyphens; custom sample names should use underscores or spaces instead. The first and last hyphens separate the three fields.

These full-drum examples use the polyphonic VOICES output, which averages stereo samples to mono per lane. The source’s MIX L/R outputs retain stereo.

05

From a pattern to a song.

Basic Groove / examples 01 + 03

The top 8vert knob selects the playing pattern: 0% = A, 10% = B, continuing through 80% = I. Changes while running take effect at the next loop boundary.

Choose the matching A–I letter on each source to edit it. The orange letter shows the edit bank; the light strip identifies the playing bank. You can edit one while another plays.

Song and Fill / examples 02 + 04

Song Mode is on in both sources, with the same arrangement. Pattern CV is disconnected so the arrangement chooses the next pattern.

Use SONG → Edit arrangement… on both sources. Keep their row order, repeat counts and pattern lengths matched so the eleven main drums and five extra percussion voices stay together.

The basic examples run at 110 BPM; the song examples run at 118 BPM with light Clocked swing. Each repeat plays one complete pattern cycle. Start begins at the first arrangement row.

Each pattern remembers its sound

A–I each store their steps, tempo, swing, length, levels, tone, tuning, decay, master/accent/choke/alternate-voice settings and sample assignments. Changing the edited pattern recalls its controls. External Clocked timing and the external effects/mixer remain patch-level settings.

Before pressing play

  • Audio 2 is connected to your output device, with a comfortable listening level.
  • Clocked is the shared transport. Every example loads stopped.
  • No unwanted mutes or solos are active; group and master levels are up.
  • In song examples, both sequencers use the same arrangement.
  • Save a new .vcv copy to keep your variations.
Dependencies and validation

Both workflows: SEQUENCER 808-16 2.10.2, VCV Fundamental 2.6.4, Impromptu Modular 2.5.0, MindMeld 2.5.1, and Rack Core Audio/Notes. Live workflow additionally: Befaco Percall and stoermelder GLUE for labels. These examples were originally authored on VCV Rack Pro 2.6.6 for macOS Apple Silicon. The 2.10.2 Mac ARM64 and Windows x64 packages share the same example audio, songs, patterns and documentation. Select the local Audio 2 device on each computer. See the installation and content guides for platform paths and optional personal libraries.

The example validations check all sixteen voices, embedded sample loading without the external libraries, mute/solo combinations, start/stop/reset/restart, and the song’s pattern progression through a complete loop. Peaks stayed below 0.34 of full scale in the provided previews. Your own changes can increase output level.

Use each example’s verification link for its measured results. This guide documents the saved examples; screenshots show the prepared Basic Groove and modular Song and Fill versions.

Troubleshooting
  • No sound: select an Audio 2 device, press Clocked RUN, check track/group/master levels, mutes and solos, and confirm that the source has a kit loaded.
  • The BPM knob seems inactive: use Clocked BPM. The sequencers are externally clocked.
  • A letter does not change playback: Basic Groove uses 8vert PAT CV; Song and Fill uses the arrangement. The letter may be selecting the edit bank.
  • Some extra drums are missing: check the lower source’s lanes 03–07 and their alternate conga/claves/maracas assignments.
  • Browser preview is silent: audition requires a monitored MIX L/R connection; the main patch uses VOICES.
  • Processed sound persists at neutral source knobs: in the prepared workflow the processing is in the WAV. In the live workflow use FADE to compare the dry path.
